# Aheera Milk — Operations & Admin Dispatch Console

Unified Operations & Farm Dispatch Console for **Aheera Store** (Pure Organics & Farm Dairy, Giridih).

## Features
- **Live Dispatch Dashboard**: Real-time Firestore order tracking across all statuses (`new`, `confirmed`, `dispatched`, `delivered`).
- **Doorstep Handover PIN Verification**: 4-digit security PIN verification on delivery.
- **Product & Inventory Manager**: Update pricing, pack sizes, stock availability, and image assets.
- **Flash Promo Studio**: Broadcast real-time announcements & promo codes to customer apps.
